# `.awproj` プロジェクト形式

`.awproj` はUTF-8で保存するJSONオブジェクトです。現在の形式バージョンは `1` です。

## フィールド

| フィールド | 型 | 内容 |
|---|---|---|
| `version` | integer | 形式バージョン。保存時は `1` |
| `source_file` | string | 元音声のパス。空文字を許容 |
| `audio_mode` | string | `source`、`silence`、`none`。旧ファイルでは省略可能 |
| `language` | string | 検出または指定された言語コード |
| `segments` | array | 文字起こしセグメント。1件以上必要 |
| `speaker_mapping` | object / null | 話者名から設定スロットへの割り当て |
| `exo_settings` | object | EXO出力およびプレビュー設定 |
| `preview_index` | integer | 選択中セグメントの0始まりインデックス |

CanvasプレビューとMP4も `exo_settings` の解像度 `width` / `height`、`fps` と字幕・画像設定を
共用します。省略時は1920×1080、30fpsです。新しい必須フィールドはなく、version 1を維持します。
MP4の保存先と音声ソースの選択は書き出し画面だけの状態です。

BGMの開始曲・終了曲・曲リスト・音量、エンディング画像・ジングル・フェード秒数・表示秒数は
`exo_settings` に保存して復元します。アプリ設定JSONへは保存せず、設定読み込みでも
現在のプロジェクトの指定を変更しません。メディア未指定の旧プロジェクトでは空の指定と
既定の音量・秒数に戻し、直前のプロジェクトの素材を引き継ぎません。
素材ファイル自体は埋め込まず、選択したファイルへのパスを保存します。

各 `segments` 要素は `start`、`end`、`text`、`speaker` を持ちます。時刻は秒単位の数値です。

## 読み込みと互換性

- ルートがオブジェクトでない、`segments` がない、またはセグメントが空の場合は読み込みに失敗します。
- 現在のローダーは `version` を検証しません。将来形式を変更する際は、先にバージョン分岐を追加します。
- `source_file` が存在すれば再生用WAVを再生成します。存在しない場合も編集・プレビュー・EXO出力は継続できますが、音声再生は利用できません。
- `audio_mode` が `silence` の場合は、最終セグメントの終了時刻までの無音WAVを再生成します。フィールドがない既存プロジェクトは従来どおり扱います。
- 話者マッピングは保存時にセグメントへ適用されます。

## 保存動作

- 初回保存と「別名で保存」は `.awproj` の保存ダイアログを開きます。
- 保存後はdirty状態を解除し、ウィンドウタイトルへファイル名を反映します。
- セグメントがないプロジェクトは保存できません。
